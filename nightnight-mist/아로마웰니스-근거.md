## 2. 아로마뱅크 상세페이지 가이드 (한글 9쪽)

- 상세페이지에 CPL Aromas 정보를 **쓸 수 있다.**
- 가능: "세계적인 마스터가 디렉팅한 최상급 향료로 개발된 OO사만의 시그니처 향" (디렉팅한 향료를 '사용한' 제품). 단, 우리 향을 크리스티안 프로벤자노가 디렉팅했는지는 **확인 전**이라 쓰지 않는다.
- 주의: "세계적인 마스터와 **콜라보**한 향", 조향사가 우리 제품을 직접 개발한 듯한 표현.
- **CPL Aromas 관련 내용은 온라인 광고 키워드로 사용 불가.** 광고 소재 문구에 넣어도 되는지는 아로마뱅크에 확인.

## 3. 자료에 없는 것

- 우리 향(슬립 인 더 포레스트)의 **참가자 수, 퍼센트, 그래프.** → 이전에 제안한 "10명 중 8명" 같은 숫자는 근거가 없어 쓰지 않는다.
- 우리 인증서가 Declaration인지 Report인지, 100% AromaWellness 향인지 'Contains'인지.
- 미스트 완제품 시험.

→ 아로마뱅크에 요청: **우리 향의 Relaxation Report(시험 방법·통과 기준·결과)**, 100%/Contains 구분, 광고 소재에 CPL·AromaWellness 이름을 써도 되는지.

## 4. 문구에 쓰는 법

- 주어는 **향료와 테스트**. "이 미스트가 긴장을 풀어 줘요"처럼 제품이 몸·마음을 바꾼다고 쓰지 않는다(화장품 의약품 오인 표현, 완제품 미시험).
- 대표 문장 "좋은 향과 몸이 받아들이는 향은 다를 수 있어요"는 시험 방법과 그대로 맞는다: Relaxation은 말이 아니라 **몸(피부전기반응)**으로 잰다.
- "편안·이완·긴장 완화" 단어를 효과로 쓰는 것은 책임판매업자 확인 후. 테스트 이름(Relaxation)과 통과 사실은 사실 진술로 쓴다.
