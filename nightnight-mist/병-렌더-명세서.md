# 나잇나잇 에어 병 렌더 제작 명세서

작성 2026-11-20 · 바이도즈 · 이 문서를 받은 Claude(또는 3D 작업자)는 아래 규격대로 병 렌더 4장을 만든다.

## 1. 무엇을 만드나

같은 병을 **같은 카메라·같은 위치·같은 크기**로 4번 렌더하고, **조명과 주변 환경만** 바꾼다.

| 파일 | 상태 | 페이지에서 쓰이는 곳 |
|---|---|---|
| `bottle-day.png` | 낮 | 제품 소개 장면 (배경 밝은 미색) — **이미 있음, 기준 이미지** |
| `bottle-dusk.png` | 노을 | 오렌지 껍질·이끼 영상 구간 (배경 황금빛 → 주황·분홍) |
| `bottle-night.png` | 밤 + 램프 켜짐 | 셋째 영상 ~ 램프 도착 직전 (배경 보라 → 남색) |
| `bottle-off.png` | 불 꺼짐 | 램프 옆에 도착해 불이 꺼진 뒤 (배경 거의 검정) |

왜 이렇게 만드나: 상세 페이지 "잠드는 여정" 구간에서 병 하나가 스크롤을 따라 내려오고, 배경이 낮 → 노을 → 밤으로 어두워진다. 4장이 같은 자리에 겹쳐 있고 스크롤 위치에 따라 서서히 섞인다. 마지막에 병이 램프 옆에 도착하면 "불 꺼짐" 장이 1.6초에 걸쳐 덮인다. **그래서 4장은 병의 모양·위치·크기가 픽셀 단위로 같아야 한다.** 조금이라도 어긋나면 바뀌는 순간 병이 흔들려 보인다.

## 2. 공통 규격 (4장 모두 동일)

기준은 지금 페이지에 들어간 `bottle-day.png`(392×1049, 투명 PNG)다. 이 이미지를 만든 씬을 복제해서 **조명만** 바꾼다.

| 항목 | 규격 |
|---|---|
| 출력 크기 | **400 × 1070 px** (페이지 표시 200 × 535의 2배). 원본은 800 × 2140으로 렌더해 보관 |
| 비율 | 200 : 535 (기준 PNG와 같음). 병이 캔버스를 꽉 채우는 지금 크롭 그대로 |
| 배경 | **투명(알파)**. 바닥·배경·바닥 그림자 없음 (페이지 배경이 따로 있음) |
| 고정할 것 | 카메라 위치·각도·초점거리, 병의 위치·회전·크기, 렌더 크롭 영역, 재질(유리·액체·캡·라벨 인쇄) |
| 바꿀 것 | 조명(방향·색·세기), 주변 환경맵(HDRI) 색, 노출 |
| 파일 형식 | PNG-24 + 알파, sRGB. 가장자리에 흰/검은 테두리(헤일로) 없이 |
| 용량 | 한 장 250KB 이하 권장 (4장을 한 번에 불러옴) |

유리에 비치는 반사색은 환경맵에서 오므로, 상태마다 환경맵 색을 아래 배경색에 맞추면 병이 그 배경 앞에 서 있는 것처럼 보인다.

## 3. 상태별 조명

페이지에서 병 뒤에 깔리는 배경색(실제 CSS 값)을 기준으로 맞춘다. 램프는 페이지에서 **병의 오른쪽**에 서 있다(병 오른쪽 30px, 바닥선 같음).

| 상태 | 뒤 배경색 | 주광 (키 라이트) | 보조광·환경 | 결과 느낌 |
|---|---|---|---|---|
| 낮 | `#F3F3E9` → `#F1E9D8` | 기준 이미지 그대로 (부드러운 자연광, 중성 5500~6500K, 왼쪽 위) | 밝은 미색 환경 | 지금 `bottle-day.png` |
| 노을 | `#EDD7B5` → `#E3B48E` → `#C98E7E` | 낮게 깔린 따뜻한 해 3000~3500K, **왼쪽 옆** 낮은 각도. 유리 왼쪽 가장자리와 캡 윤곽에 주황 하이라이트 | 분홍·모브 톤(`#C98E7E`~`#9A7790`) 약하게 채움 | 해 질 녘, 병 전체가 살짝 주황으로 물듦 |
| 밤 (램프 켜짐) | `#9A7790` → `#62627F` → `#33374C` | **오른쪽에서 오는 램프 빛** 2700K, 병 어깨 높이보다 조금 위, 작은 광원. 유리 오른쪽 면과 캡 오른쪽에 따뜻한 하이라이트 | 왼쪽·뒤는 푸른 보라 주변광(`#62627F`) 낮게 | 어두운 방, 옆 스탠드 불빛만 병을 비춤 |
| 불 꺼짐 | `#10121B` | 없음 (램프 꺼짐) | 아주 약한 차가운 빛 7000K 이상, **뒤 왼쪽**에서 윤곽만 (창문 달빛 느낌) | 거의 실루엣. 병 윤곽과 캡 경계만 희미하게 보임. 라벨 글씨는 안 읽혀도 됨 |

- 노출: 낮 > 노을 > 밤 > 불 꺼짐 순으로 어두워진다. 불 꺼짐도 **완전한 검정은 아님**(윤곽이 배경 `#10121B`보다 살짝 밝게).
- 액체 색은 바꾸지 않는다. 빛 색 때문에 달라 보이는 것만 허용.
- 유리 반사에 실제 방·창문 같은 형태가 비치지 않게 한다. 색만 비치게.

## 4. 파일 이름과 전달

- 이름: `bottle-day.png`, `bottle-dusk.png`, `bottle-night.png`, `bottle-off.png` (소문자, 하이픈)
- 넣을 곳: 저장소 `bydose_web`의 `imweb/product-pages/assets/air/` (낮 장은 이미 있음 → 새 규격 400×1070으로 다시 뽑으면 덮어쓰기)
- 넣으면 페이지의 임시 필터(`.is-temp`)를 빼고 파일만 바꿔 끼운다.

## 5. 넘기기 전 확인

- [ ] 4장 모두 400 × 1070 px, 투명 배경
- [ ] 4장을 같은 위치에 겹쳐 놓고 번갈아 켜 봤을 때 병 윤곽·캡·라벨 위치가 1px도 움직이지 않는다
- [ ] 바닥 그림자·배경색이 이미지에 남아 있지 않다
- [ ] 가장자리에 흰 테두리(헤일로)가 없다 — 어두운 배경(`#10121B`) 위에 올려서 확인
- [ ] 낮 장에서 라벨(byDOSE, 50mL 1.7 fl.oz., 캡 문구)이 읽힌다
- [ ] 밤 장에서 빛이 **오른쪽**(램프 쪽)에서 온다
- [ ] 한 장 250KB 이하
