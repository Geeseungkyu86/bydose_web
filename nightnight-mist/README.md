## 상세페이지에 가져갈 것 (구조만, 문구는 베끼지 않음)

옵타움 페이지에서 본 구성 순서:
1. 상단 Key Point 5개 → 2. 감성 서사(향 이미지) → 3. 향 노트(TOP/MIDDLE/BASE) + 지속 시간 설명 → 4. 시험 근거 블록(숫자 크게) → 5. 시간을 박은 사용 루틴(23:00 → 23:03) → 6. Q&A(다른 제품과 뭐가 다른지) → 7. 제품 정보 표·주의사항

가져갈 만한 것:
- **사용 장면을 시각으로 보여주기.** "몇 시에 무엇을 하고, 어디에 몇 번" 형태가 바로 이해된다. 나잇나잇 크림 루틴과 이어 붙일 수 있다.
- **향 노트 표기.** 향을 파는 제품이면 TOP/MIDDLE/BASE와 지속 시간을 한 블록으로 정리한다.
- **"이게 뭐다"를 먼저 정하는 Q&A.** 옵타움은 "필로우 미스트 vs 섬유향수"로 카테고리를 세운다. 우리도 미스트가 무엇과 다른지 한 문장으로 먼저 정한다.
- **선물 프레임.** 옵타움은 상품명 앞에 '숙면선물', 밤하늘 선물박스, 쇼핑백 추가 구성으로 선물 수요를 잡는다.

따라 하지 않을 것:
- **뇌파 "스트레스 감소" 같은 심리 효능 주장.** 옵타움은 5명 시험을 근거로 내세운다. 우리 카피 원칙(심리 효능·인과 사슬 금지, 과장 효능 금지)에 어긋나고 표시광고 위험이 크다.
- **상시 할인가를 기본가처럼 보여주기.** 정가 35,000원을 걸고 늘 25,000원에 판다.
- **경쟁 제품 직접 비교.** 외부에 보이는 문구에는 넣지 않는다.
- **경쟁사 리뷰 재게시.** 리뷰는 내부 분석 용도로만 쓴다.

## 두 가지 용도라서 지킬 것 (몸 + 베개)

몸에 뿌리면 **화장품**, 베개·침구에 뿌리면 **생활화학제품(섬유용 방향제)**으로 본다. 두 용도를 함께 쓰면 보통 두 쪽 기준을 모두 맞춰야 한다. 옵타움도 생활화학 안전인증 번호와 화장품 사용상 주의사항을 함께 싣고 있다. 아래는 일반 기준이니 최종 판단은 제조사·책임판매업자와 식약처·환경부(초록누리) 기준으로 확인한다.

- **표시:** 화장품 전성분과 사용상 주의사항, 그리고 생활화학제품 표시(안전확인 번호, 용도·제형, 주요물질, 알레르기물질 등)를 둘 다 싣는다.
- **쓰면 안 되는 표현:**
  - "숙면", "수면 개선", "불면" 같은 수면 효과 → 의약품으로 오인될 수 있음
  - "스트레스 감소", "긴장 완화" 같은 심리 효능 → 우리 카피 원칙 위반
  - "항균 99.9%", "유해균 제거" → 살생물제품 승인 대상이 될 수 있어 승인 없이는 쓰지 않는다
- **쓸 수 있는 방향:** 향 자체(향 노트, 지속 시간), 쓰는 장면(잠들기 전 몸과 베개에 뿌리는 루틴), 확인된 시험(피부 저자극 등, 기관·날짜·인원까지 확인된 것만).
- **알레르기:** 라벤더 아로마 오일이 들어 있어 알러지 프리가 아니다. 알레르기 유발 성분을 표시하고, "알러지 프리", "자극 걱정 없는" 표현은 쓰지 않는다.
- **사용법은 용도별로 나눠 쓴다.**
  - 몸: 분사 거리, 피해야 할 부위(눈 주위, 상처), 처음 쓸 때 패치 테스트 안내
  - 베개: 분사 거리와 횟수, 원단 얼룩 테스트, 마른 뒤 사용
- **에탄올 베이스라면:** 화기 주의, 어린이 손 닿지 않게 보관 문구를 넣는다.
