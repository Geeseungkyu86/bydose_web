# 기술 적합성 확인서 이미지

사용 권한·외부 공개 범위를 확인한 실제 `GW ONE RELAX SC` 기술 적합성 확인서만 이 폴더에 넣습니다. 가짜 인증서나 완제품 수면 효과 인증 이미지를 사용하지 않습니다.

예정 경로: `assets/documents/gw-one-relax-sc-compliance.jpg`

실제 세로형 원본을 위 이름으로 저장한 후 프로젝트 루트에서 `python tools/build_html.py`를 실행합니다. HTML 생성기는 파일이 있을 때만 미리보기와 확대 링크를 연결합니다. 미연결 상태에서는 깨진 이미지 요청 없이 명시적인 삽입 영역을 표시합니다. 원본 비율은 `object-fit: contain`으로 보존합니다.

확대 링크는 새 탭에서도 열 수 있고, JavaScript 사용 시 대화상자로 확대됩니다. PDF 원본을 별도 제공하려면 승인된 PDF를 이 폴더에 추가하고 생성기의 링크를 변경합니다. 최종 PDF 조판은 후속 범위입니다.
