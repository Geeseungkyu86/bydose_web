# nightnight2 — 나잇나잇 크림 유통(도매) 상세페이지

자사몰 상세페이지(https://bydose.kr/shop_view?idx=63)를 도매 사이트에 올릴 **이미지형 상세페이지**로 바꾸는 작업. (2026-10-27)

- 가로 1080px 한 장 기준. 모바일과 PC에 같은 이미지를 쓴다.
- 영상(Vimeo) 3개는 GIF로 바꿨다.
- 피그마: [나잇나잇 크림_유통 상세페이지](https://www.figma.com/design/ABZY52TMgJsU8hn5OQ41Ia?node-id=1-2) (현재 검토 중인 레이아웃)

## 만든 방식

1. 자사몰 상세 영역(`#nnd-story`)의 HTML과 CSS를 그대로 가져왔다 → `src/`
2. 모바일 CSS(768px 이하 규칙)를 항상 적용되게 풀고, 폭 360px으로 고정했다.
3. 피그마로 옮긴 뒤 3배로 키워 1080px로 맞췄다. 본문 15px → 45px이라 폰에서도 읽힌다.
   (기존 `smartstore-860` 이미지도 모바일 레이아웃을 키운 방식)
4. 영상 자리에는 첫 장면(포스터)을 깔고, 그 위에 GIF를 채웠다.

## 자사몰과 다른 점 (도매용)

| 구분 | 내용 |
|---|---|
| 뺐다 | 10/31 세일 가격 배너(`bd-promo`), 배송 안내·교환/반품 안내(자사몰 기준), "○○의 나잇나잇 →" 페이지 안 이동 링크 |
| 펼쳤다 | 상품정보 제공고시, 전성분, 사용 시 주의사항, 아로마 웰니스 인증서, 조향 설계 (아코디언 모두 펼침, +/× 아이콘 숨김) |
| 피그마에서 고쳤다 | 리뷰 별점 아이콘(SVG가 깨져서 별 도형으로 교체) |

## 폴더 구조

```
nightnight2/
├── build.py        src/ → out/ 1080용 HTML 생성
├── make_gif.sh     video/ → gif/ 변환 (ffmpeg 필요)
├── src/
│   ├── story.html    자사몰 #nnd-story 원본 HTML
│   └── nnd.css       자사몰 상세 CSS 원본
├── img/            상세 이미지 (긴 변 1080px로 줄인 것) + 영상 포스터 poster_*.jpg
├── gif/            GIF 3개 (720px 정사각 · 8fps · 4.5~5초 · 각 6~9MB)
├── video/          Vimeo 원본 영상 (1080p)
└── out/
    └── detail_local.html   미리보기용 (브라우저 폭 360px로 보면 됨)
```

피그마에서는 1080 칸에 1.5배로 늘어나 있어 약간 흐릴 수 있다.

## 다시 만들기

```bash
python3 build.py local    # out/detail_local.html (미리보기)
python3 build.py inline   # out/detail_inline.html (이미지 내장, 약 21MB — 피그마 업로드용, 저장소에는 안 올림)
bash make_gif.sh          # GIF 다시 뽑기
```
