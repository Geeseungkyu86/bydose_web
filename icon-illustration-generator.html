주제나 키워드(성분/효과, 감정, 계절, 일상 등 무엇이든)를 입력하면 section4~6에 쓰인 것과 같은 방식(아메바 clip-path 블롭 + 블러 + 그레인)의 카드 아이콘을 자동으로 만들어줍니다. 모바일에서는 세로 9:16, PC에서는 가로 16:9로 화면 비율이 자동으로 바뀝니다(뷰포트 폭 992px 기준). 아래 코드를 그대로 복사해서 imweb 코드위젯에 붙여넣으면 됩니다.

PC · 16:9 가로

위 블록을 통째로 붙여넣으면 됩니다. 클래스명이 매번 새로 생성되는 고유 접두사(gen-xxxx)를 쓰기 때문에, 같은 페이지에 여러 개를 붙여넣어도 서로 충돌하지 않습니다. 화면 비율은 CSS 미디어쿼리(max-width: 992px)로 자동 전환되며, imweb 쪽 모바일/PC 분기 기준과 동일합니다.
